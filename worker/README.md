# Agentiz Worker

Эта папка зарезервирована под отдельный Python-сервис исполнения задач Agentiz на базе
OpenHands Software Agent SDK.

Сейчас здесь находится только исследование и каркас реализации. Рабочий worker, зависимости и
контейнерные манифесты намеренно ещё не добавлены.

Основной документ: [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).
